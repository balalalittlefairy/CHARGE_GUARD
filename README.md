# CHARGE GUARD · 充电守护

通过米家智能插座，根据 Android 手机电量自动开启和关闭供电的 Kotlin 应用。

当前版本 **0.4.2**，支持 **Android 8.0（API 26）及以上**。目标设备为米家智能插座 3：**ZNCZ301KK / `cuco.plug.v3`**。本项目是独立社区实现，与小米无隶属关系。

## 功能

- **双阈值循环**：默认电量 ≤ 30% 开启、≥ 80% 关闭，中间区间保持状态。
- **三种控制路线**：自动（局域网优先、云端备选）、仅局域网、仅云端。
- **明确开关与确认**：发送开启或关闭命令后读回状态，未确认时不显示成功。
- **小米账号接入**：官方网页登录、设备列表与凭据获取，保留密码登录和手动导入入口。
- **后台保护**：前台服务、运行通知、停止入口、电量复查与有限重试。
- **原生界面**：首页、保护、设置及可筛选的运行记录，支持大字体和窄屏换行。
- **本地加密存储**：Android Keystore + AES-GCM 保存设备凭据及账号会话，禁用备份和迁移。

## 开始使用

1. 在米家 App 完成插座配网和账号绑定，把手机充电器接到目标插座。
2. 从 [GitHub Releases](https://github.com/balalalittlefairy/CHARGE_GUARD/releases/latest) 下载并安装 APK，也可以按下方步骤从源码构建。
3. 在「设置 → 小米账号」选择与米家一致的地区，使用手机号 / 验证码登录，完成后获取设备并选择目标插座。
4. 先刷新状态，再手动测试开启和关闭，核对实际插座动作。局域网要求手机与插座网络互通。
5. 在「保护」页设置两个阈值和路线，点击「保存保护设置」，再到首页「开始保护」。允许通知，并按手机系统要求开放后台运行。

已有 IP 与 Token 时，可从高级配置手动导入，单独使用局域网。云端需要有效小米会话和设备 DID；只导入 IP / Token 不足以启用云端。验证码错误或取消时，可使用「继续未完成的身份验证」；会话过期需重新登录。

## 保护规则

阈值范围为 `1 ≤ 开启阈值 < 关闭阈值 ≤ 100`。开始时同样按两个阈值判断，在区间内读取并保持当前开关状态。

| 情况 | 行为 |
| --- | --- |
| 电量 ≤ 开启阈值 | 开启并读回确认 |
| 电量 ≥ 关闭阈值 | 关闭并读回确认 |
| 两个阈值之间 | 保持当前状态 |
| 一轮操作失败 | 每轮最多 3 次，失败后分别等待 10 秒、30 秒 |
| 开启一轮仍失败 | 提醒；相对本轮起始电量，每下降 1 个百分点再试一轮 |
| 关闭一轮仍失败 | 提醒；相对本轮起始电量，每上升 3 个百分点再试一轮 |
| 到 100% 仍未确认关闭 | 结束保护并提醒；已发出的关闭命令允许完成确认 |
| 手动停止 | 停止保护，保留插座当前状态 |

关闭阈值设为 100% 时，首次达到 100% 仍执行一次关闭，失败后不再重试。运行期间锁定配置及手动开关；保存设置本身不会启动保护。升级后应检查配置并手动重新开始。

自动路线在局域网连接失败时尝试云端；若局域网写入可能已执行，先通过云端查询实际状态，再决定是否发送同方向命令。两条路线串行执行。

## 验证状态与限制

真实账号登录、设备列表和手动插座开关已有验证；云端已验证实时查询和原状态写回，也验证过绑定手机移动数据的请求。**云端实际切换继电器、真实充放电跨阈值和长时间后台场景仍待验收**。

- 仅面向上述型号，不包含插座配网、局域网自动扫描或 IPv6。
- 局域网使用家庭私有 IPv4；云端要求插座联网、手机有互联网、会话有效且账号有设备权限。
- 状态确认来自设备协议读回，不是对继电器或充电电流的独立测量。
- Doze、厂商省电、网络延迟或强行停止可能中断保护；30 秒采样及非精确闹钟不保证固定执行时刻。
- 小米社区接口变化可能影响兼容性，不绕过 HTTPS 证书校验或登录风控。
- 运行记录最多保留最近 30 条进程内记录，支持界面重建恢复，不是跨进程持久历史。

## 从源码构建

使用 JDK 17 和 Android SDK 35。通过 Android Studio 打开项目并配置 SDK，或在本机 `local.properties` 中设置 `sdk.dir`。

```powershell
.\gradlew.bat assembleDebug
```

macOS / Linux 使用 `./gradlew assembleDebug`。首次构建需要联网下载 Gradle 和依赖；APK 输出至 `app/build/outputs/apk/debug/app-debug.apk`。

GitHub Release 当前提供调试签名 APK。不同签名的包无法直接覆盖安装；卸载会清除本地配置。
